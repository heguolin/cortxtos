# 检索评估集（ADR 0008）

一切检索调参的前置与回归护栏：`pnpm eval` 输出文档级 Hit@1/@3/@6。**没有前后数字不做调参。**

## 格式

```json
{
  "entries": [
    { "query": "问题的中文表述", "expectDocument": "期望命中的文档标题", "note": "单跳/多跳/同义改写/无答案" },
    { "query": "……", "expectDocument": "__none__", "note": "无答案类：观察检索是否被无关内容干扰，不计 Hit@k" }
  ]
}
```

- 命中口径 = **文档级 Hit@k**：期望文档出现在检索结果前 k 名即命中（不看 chunk）。
- 三类覆盖：单跳事实 / 同义改写·跨语言 / 无答案。

## 当前状态（重要）

`eval-set.json` 目前是**本地起步语料版**（demo.md / sqlite-vec 笔记 / MCP 文章，9 条）。本地基线：Hit@1/3/6 = 100%（小语料满分是预期行为，不代表生产检索质量）。

**扩充到 ≥20 条必须针对服务器上的真实语料**（Deep Agents 系列 PDF 等）编写条目，然后：

1. 在服务器跑 `pnpm eval`（或把语料同步到本地）得到真实基线；
2. top3 < 80% → 按票 06 接入 rerank / 调参；top3 ≥ 80% → 记录数字结论，暂不接入。
