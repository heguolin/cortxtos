# ADR 0001 — 自托管私有部署取代"本地优先"

**状态**：已接受（2026-09-18，用户裁决）

## 背景

原需求书定位"本地优先（Local-First）：程序跑在个人 PC 上，把个人计算机升级为大脑皮层"。 grilling 第二轮用户明确：程序要部署到**自己的云服务器**（腾讯云轻量 106.55.102.231，CentOS Stream 9），从浏览器访问。

## 决策

产品形态 = **自托管私有部署**：单 Node 进程跑在用户自己的服务器上，单用户，数据 100% 存服务器。"本地优先"一词在所有文档中改写为"自托管"。

## 后果

- 出局：Electron 桌面壳、托盘/全局热键、TUI 主形态、本地 Ollama 模型（服务器无 GPU）、离线可用（用户确认不需要）。
- 新增必需：密码认证 + HTTPS（公网暴露）、文件上传通道（Vault 不再是本地文件夹）。
- v1 的"手机 App + PC daemon + WS 桥"方案一并作废。
