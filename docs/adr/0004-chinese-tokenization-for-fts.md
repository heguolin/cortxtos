# ADR 0004 — FTS5 中文分词走 @node-rs/jieba

**状态**：已接受（2026-09-18，技术决策，实现方裁量）

## 背景

FTS5 默认 unicode61 分词器对中文几乎失效（无词边界 → 整句成 token → 召回崩坏）。知识库问答是主轴且内容以中文为主，痛点 ②（检索质量差）的正解必须处理这一条。

## 决策

索引与查询**两侧统一**用 `@node-rs/jieba`（预编译二进制，避免 nodejieba 的 native 编译坑）分词后写入/查询 FTS5。向量检索（sqlite-vec）不受影响，作为召回的另一条腿。

## 后果

- 新增一个预编译依赖（锁版本）。
- 分词器升级不触发全量重建（可选：重建以对齐新旧索引，`reindex` 已有能力）。
