# 04 · 入库管线：抽文本 → 分块 → FTS5 + 向量

**What to build**
- 文档状态机：`queued → indexing → ready / failed(错误信息) + 重试按钮`；任一环节失败不污染 Vault。
- 抽文本：md/txt 直读；PDF 用 Node 侧解析库，**保留页码**。
- 分块：标题层级感知，目标 ~500 token、重叠 ~15%；chunk 记 `document_id + page + heading_path + token_count`。
- 索引双写：@node-rs/jieba 分词入 FTS5（ADR 0004）；嵌入走 `embedding` 档（OpenAI 兼容 `/v1/embeddings`，BGE-M3 系）写 sqlite-vec。
- 每次嵌入调用强制落 `usage_records(purpose='embed')`。
