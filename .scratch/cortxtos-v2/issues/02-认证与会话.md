# 02 · 认证：单用户密码 + 会话 + 限速

**What to build**
- 登录页（Vue）+ `POST /api/auth/login`；argon2id 哈希；会话存 SQLite，Cookie HttpOnly + Secure。
- 密码生命周期（DESIGN §8）：首次启动从 `.env` 的 `APP_PASSWORD` 种子入 DB，**此后以 DB 为准**（库中已有密码时 `.env` 忽略）；设置页改密写 DB。
- 登录失败限速（5 次失败锁 5 分钟）；鉴权中间件保护全部 `/api/*`。
