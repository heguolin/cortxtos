# 01 · 骨架：单包 TS 工程 + 配置 + SQLite 基线 + 部署件

**What to build**
- pnpm 单包，TypeScript ESM，Node ≥ 22.19；`src/server`（daemon）+ `src/web`（Vue 3 + Vite + Tailwind，构建产物由 daemon 静态托管）。
- 配置加载：`.env`（`APP_PASSWORD` / `LLM_API_KEY` / `LLM_BASE_URL`）+ `<dataDir>/config.json`（ModelProfile 四角色阵容等）；zod fail-fast 校验——**未知键直接报错**，防手改拼写静默通过。
- SQLite 迁移器：幂等、WAL；基线迁移建全 DESIGN §6 全部表（documents/chunks/chunks_fts/chunk_vec/sessions/messages/jobs/runs/usage_records/kv）。
- HTTP 骨架：`/healthz`，单实例端口绑定（二次启动拒绝）；`bin/cortxt.mjs` 入口。
- 部署件：`Dockerfile`（node:22 多阶段）、`docker-compose.yml`（app + caddy，`/data` 卷）、`Caddyfile`（cortxt.hgl123.icu 反代 443）、`deploy.sh`（装 Docker → 起服务 → 配 swap → 健康检查）、`.env.example` + `config.example.json`。

**Blocked by** 无

**验收清单**
- [ ] `pnpm dev` 起 daemon，`GET /healthz` 200
- [ ] 配置含未知键 → 启动即报错且指出键名（不静默）
- [ ] 迁移连跑两遍无 diff（幂等）；WAL 已开启
- [ ] 二次启动同端口 → 明确拒绝
- [ ] `docker compose config` 校验通过；typecheck 干净

ready-for-agent: ✅
